# Northline frontend

Angular 19 client for the banking API.

## Scripts

```bash
npm install
npm start      # http://localhost:4200 with /api proxy
npm run build
```

## Screens

- `/login` — sign in
- `/register` — create customer + user
- `/app` — accounts overview
- `/app/move` — deposit / withdraw / transfer
- `/app/activity` — statement
