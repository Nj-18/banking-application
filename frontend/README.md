# Northline frontend

Angular 19 client for the banking API.

## Scripts

```bash
npm install
npm start      # http://localhost:4200 with /api proxy → :8081
npm run build
```

Backend default port is **8081** (`server.port` in `application.properties`).

## Screens

- `/login` — sign in
- `/register` — create customer + user
- `/app` — accounts overview
- `/app/move` — deposit / withdraw / transfer
- `/app/activity` — statement
